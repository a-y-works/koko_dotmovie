## この台本について

v1が会話劇だったのに対して、こちらは朗読一本。相手役もAI音声もいない。立っているのはひとりで、頼れるのは声と間だけ。

谷川俊太郎の朗読詩に寄せて、ひらがなを多く、一行を短く、分かち書きで書いてある。声に出したときの拍がそのまま行分けになっているので、**台本の改行は改行ではなく息継ぎの指示**。

**歌への渡し方**：最後の連で「ごおくねん まえから ここで うたって いた ものが いる」と言って、Plants Songに入る。つまりこの7分で歌われる歌は主役の歌ではなく**植物の歌**。曲名をそのまま構成に使ってある。

## 改訂のあと

三度直している。どれも外からの指摘や話し合いがきっかけで、どれも直して良くなった。

### v2.1　三の連
「名前が客席に伝わらない」という指摘を受けての改訂。名前をメジャーなものに差し替えるのではなく、**名前の直後に「それが何か」を一行つける**形にした。スギナ＝つくしの成長した姿、カラスノエンドウ＝子どもが笛にするあの豆。**知らないと思っていたものを、実は知っていた**という体験がそのまま起きるので、「雑草がスギナになる」という説明の三行を削ってもテーマが通る。

### v2.2　五の連
「草は地球のかさぶたではないか」という先生からの助言を受けての改訂。**五の連にはもともと「なおらない。」という一語があり**、かさぶたの比喩はそこにそのまま噛み合った。「治らない」ではなく「治っている最中」へ裏返り、さらに草→土→草の循環へ開く。

入れ替わりに「でも それは／こわれて いるのでは なくて、」の二行を削除。同じ仕事をかさぶたのほうが具体的にやってくれるため。

**結果として、三の連が「見方」（名前の話）、五の連が「はたらき」（草が何をしているかの話）を受け持つ形になり、柱が二本立った。**競合しない。

### v2.3　五の連の最終行
話し合いの結果、最後の一行を **「この はたけ は／いきて いる／と いう こと だ。」** に変更。「はじまった ばかり だ。」からの差し替え。かさぶたと循環の流れはそのままで、着地だけが変わった。

**「いきて いる」は結論ではなく状態なので、言い終わっても空気が開いたままになる。**直後の「しずかに して。／きこえる。」に、より自然に繋がる。

**★この台本の背骨（その一）**　「てき は なまえ を しらない あいだ だけ てき だ」。**声は張らない。**むしろ小さいほうが効く。張るのは「駆除」の一語だけで足りる。

- **スギナは差し替えない。**つくしとの関係を知らない人が多いぶん、いちばん効く。**この一組がこの連の心臓**

## 曲中の演出とアレンジ

Plants Songは葉菜類→根菜類→果菜類→穀類→種子植物と進んで種に戻る。曲そのものが一本の物語なので、演出はそれをなぞるだけで成立する。コード進行はほぼ全編ワンループなので、編曲は**足し算と引き算の設計がすべて**。

| セクション | 動き | バンド |
|---|---|---|
| イントロ | 中央でしゃがみ背を丸める（種の姿勢）。動かない | キックとシンセループだけ。**ベースはまだ入れない** |
| 葉菜類 | ゆっくり立ち上がる。腕を左右に開く | キック＋ハット。スカスカにするほど後半が効く（Perfume的な引き算） |
| 根菜類 | 目線は下。足で床を強く踏む。上半身は動かさない | ベースIN、低域中心。サブベースのサイン波を1本ずっと |
| **果菜類★** | 虫が飛んでくる方向を目で追い、両手を広げて**迎え入れる**。曲中唯一の笑顔 | 全部入り。四つ打ち＋クラップ、最大音量 |
| 穀類 | 腕を下ろし膝を折る（枯れる）。顔は上げたまま | **ドラムを完全に抜く**。パッドとアルペジオのみ（サカナクション的な落とし方） |
| 種子植物 | 両手で何かを包み、客席へ差し出す | キック→ベース→ハット→クラップと1小節ずつ積む |
| ララララ | 客席に手拍子を煽る。舞台を大きく使う。客席も明るく | フルバンド |
| 間奏 | セリフは入れない | **朗読の「なまえ」の録音を16分に刻んでシンセと絡ませる**。スギナ・つくし・ミミズが楽器になって戻ってくる |
| ラスト | 正面を切って動かずに歌い切る | 最大。最後の一音でブレイク |

### 果菜類パートがこの企画のいちばん強い4小節
- この曲でここだけ、**花に虫や鳥が寄ってきて受粉が起きる場面**が歌われる
- さらにこのパートに並ぶ野菜名に**トマトとスイカ**が入る。四の連で「わたしの トマトも、わたしの スイカも」と言わせてあるのは、ここへの伏線

### 実務メモ
- **BPM**：ライブ版でまずクリックを取る。四つ打ちに寄せるなら118〜126あたりが手拍子と合いやすい
- **キー**：原曲Cで声域に合わなければ遠慮なく移調。ワンループなので移調しても演奏難度は変わらない
- **朗読中の音を同期音源で流すなら**ドラマーにクリック必須。リハ時間が取れないなら、朗読は**ドローンとパルスだけ手動再生**にしてバンドは完全生のほうが事故が少ない

## 演者ノート

### 抑揚を捨てる稽古がいる
ミュージカルの発声は、語尾と音程で感情を運ぶ。この朗読はその逆で、**平たく読むほど言葉が立つ**。とくに三の連の名前は、気持ちを込めた瞬間に説教になる。名簿を読む、点呼を取る、そのくらいの温度で。

### 三の連だけ、声を二種類つかう
名前（スギナ、カラスノエンドウ…）は**点呼の声**。そのあとの「── つくしが、おとなになったすがた。」は**内緒話の声**。名前と正体のあいだに**必ず一拍あける**のがコツで、ここを詰めると全部が説明文になる。

「── てんとうむし。」の一行だけ、客席が小さく笑う設計。**笑いを待たないこと。**待つと狙って言ったことがばれる。

### 強く出すのは一箇所だけ
**「駆除」**。ここだけ言い切って、あとは全部それより下で構成する。「てき は なまえ を しらない あいだ だけ てき だ」も「この はたけ は いきて いる と いう こと だ」も背骨だが、どちらも声量ではなく**その前の間**で立てる。

### かさぶたを気持ち悪く読まない
五の連のかさぶたは、だれもが子どものときにやった**「はがしたくなる」**という経験のこと。血やかさぶたの不快さを強調すると、客席がそこで止まって次の「つちが むきだしに なると」に乗ってこない。**軽く、ちょっと懐かしそうに。**ここだけ少し笑みが混ざってもかまわない。

### 転換点は四つ
1. **「しずかすぎる、と おもった あさ が あった。」**（1:00頃）── まだ気づいていない。違和感だけがある状態
2. **「なまえ を しって しまう と、もう、ころせない。」**（1:48頃）── 腑に落ちた。小さい声でいい
3. **「── ちがう。」**（2:22頃）── 自分の言ったことをその場で訂正する。ここから畑の見え方が裏返る
4. **「しずかに して。」**（2:52頃）── 客席に向かって言う。この上演で唯一、客席に直接話しかける一行

### 間は数えて作る
「間　二拍／三拍／四拍」は飾りではない。本番で不安になると必ず間が縮む。稽古で**心の中の拍数を決めて**おくこと。とくに**五の連は間が五か所**あって、ここを詰めると台本がただの説明文になる。

### 歌に入ったら役が二重になる
朗読の「わたし」を保ったまま、同時に植物になる。完全に植物になりきると、7分が2つの別の出し物に割れる。**果菜類パートで虫を迎え入れる瞬間**が「わたし」と植物の重なる場所で、この作品最大の見せ場。

### 最後の三行
大きな声を出さない。何も解決していないから。明日も草は生えるし虫は来る。変わったのは**それを敵と呼ばなくなったこと**だけ。

## 尺の調整

五の連が長いぶん、全体は約7分45秒。7分前後に収めたい場合の削りどころ。上から順に影響が小さい順。

- **前奏を8秒→4秒**　−4秒　／　影響ほぼ無し
- **一の連「おもい／つめたい／ちょっと、あまい」を1行に**　−8秒　／　手触りの描写が減るだけ
- **四の連「ハチが〜クサが〜」の4行を2行に**　−10秒　／　**いまはここがいちばん削りやすい**。循環の話を五の連の最後が引き受けたので、四で先に言っておく必要が薄れている

この三つで**約7分23秒**。さらに必要なら下記も検討できるが優先度は下がる。

- **三の連からヒラタアブを抜く**　−9秒　／　五つ→四つ
- **五の連「はがしたく なる。」を抜く**　−4秒　／　客席の体感といちばん繋がる一行なので最後の手段に

**削ってはいけない三か所**：三の連の「──」の行（名前が伝わらなくなる）、三の連のミミズ（終わりの循環が効かなくなる）、五の連の「── ちがう。」（かさぶたが唐突に始まる）。

逆に伸ばしたい場合は、**間を伸ばすのがいちばん安全**。

## 客席が農大関係者であることへの備え

- **かさぶたの比喩**　裸地になった土は雨で表土が流れる。そこに最初に入って地表を覆うのが先駆植物（パイオニア種）で、土が肥えてくるにつれ別の種に置き換わっていく。**傷を覆い、治ったら自分で落ちる**という点までかさぶたと対応する。自然農や不耕起栽培で「土は裸でいたがらない」という言い方をするのと同じ考え方
- **「畑は毎年耕すから治り終わらないのでは」と聞かれたら**　そのとおりで、台本は「治った／治らない」で終わらせていない。くさ→つち→くさ の循環を見せたうえで**「いきて いる」**と言っている。治癒の完了ではなく、続いている状態の話なので、突かれても強いほうに倒れる
- **スギナ＝つくし**　同じ地下茎から出る同じ植物。春に出る胞子茎がツクシ、そのあと伸びる栄養茎がスギナ。しかもスギナは**畑でいちばん嫌われる難防除雑草のひとつ**。「子どもの頃うれしかったものが、いま憎んでいるもの」という構図が事実として成立している
- **カラスノエンドウ**　さやを笛にする遊びから「ピーピー豆」などと呼ばれる。農学的には、春先にアブラムシがついて、それを食べるテントウムシやヒラタアブを先に増やす。天敵温存植物（バンカープランツ）の考え方そのもの
- **ヒラタアブ**　ハチに似ているがハエの仲間（双翅目）。幼虫がアブラムシを食べる代表的な天敵。「はちのふりをしたはえ」は正確な説明
- **「なんびゃくおく」**　土壌1gあたりの微生物は数億〜数十億個とされる。ひとにぎり（約100g）なら数百億。むしろ控えめな数字
- **「ごおくねん」**　陸上植物の出現が約4.7〜5億年前。地球誕生（約46億年前）ではなく、植物が陸に上がってからの時間
- **「キン が くばり」**　菌根菌のこと。植物の根と共生してリン酸や水の吸収を助ける。二の連の「きん を ころす」と対になっている
- **トマト・スイカ**　熊本県はどちらも収穫量で全国上位（近年1位が続いている）。パンフレットに書く場合は最新年次の統計を要確認

## 上演前に学校へ確認すること

既成曲を使う以上、事前に担当部署へ確認しておいたほうがいい項目。法律家による助言ではないので、最終判断は学校を通して。

- **既存音源やカラオケ音源を流す場合** ── 生演奏とは別の扱い
- **当日の様子を動画で公開する場合** ── YouTube・SNSへの投稿は上演とはまったく別の手続き
- **歌詞をパンフレットに印刷する場合** ── これも演奏とは別
- **いちばん早い確認方法** ── 学校がJASRAC等と包括契約を結んでいるかを事務局に聞く
