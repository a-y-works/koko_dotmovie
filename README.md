# ここにいる — Pixel poetry film

朗読劇 v2.3 を基にした、レトロRPGの会話演出による映像初稿。1280×720 / 24fps / 3分50秒、H.264 + AAC。

## 視聴

`output/koko-ni-iru.mp4` を動画プレイヤーで開くか、このディレクトリで `python3 -m http.server 8000` を実行して `index.html` を開いてください。ページに章ジャンプとダウンロードがあります。

## 再生成

Python 3、FFmpeg、Noto Sans CJK が必要です。現在の環境には導入済みです。

```sh
cd /workspace/koko_dotmovie
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python render.py
```

`--preview` は冒頭15秒を出力します。映像・音楽はシードに依存せず再生成できます。`assets/script.md` が提供された台本、`timeline.json` が台本から生成される57ページの字幕タイムラインです。変更は `render.py` の時間割・音響設計・描画処理で行います。タイムラインJSONは再生成で上書きされます。

## 改訂2：BGMと会話音

ユーザー提供の3曲をステレオのまま使用。尺や音程は変えず、各曲の冒頭から対応区間の長さを採用しています。各入りに0.45秒、終わりに0.65秒のフェードを付け、曲間の音量差を調整しました。元音源は `assets/bgm/` に保存しています。

| 映像の時間 | BGM | 使用する元音源区間 |
|---|---|---|
| 0:00–1:04 | 不穏な前半 | 0:00–1:04 |
| 1:04–2:16 | なまえ〜ごおくねん | 0:00–1:12 |
| 2:16–3:04 | きこえる-歌への助走 | 0:00–0:48 |
| 3:04–3:34 | 初稿のオリジナルインスト | 30秒 |
| 3:34–3:50 | 無音 | 終幕 |

従来の合成ドローン・朗読部の自作パッド・追加キックは取り除きました。提供BGMそのものに含まれる低音は維持しています。「ごおくねん」の区間も、今回の指定に従い提供BGMを再生します。

文字音は短いパルスに声の共鳴に似た成分を加えた独自音。「駆除」は低く強く、名前の説明は軽く、それ以外は落ち着いた低めの声にしています。既存ゲームからの音源抽出はありません。句読点・改行は休止、空白は無音。文字表示とSEは同一の `reveal_times` を使用し、24fpsにして表示の刻みを細かくしました。BGMは発音時にわずかに下げています。

台本・総尺・ドット絵の構成は初稿を継承。終幕は文字音も含め無音です。全57ページの字幕、文字の揺れ、畑が白くなってから緑が戻る演出があります。`sound.py` が音響、`render.py` が文字送りと映像、`output/audio-cues.json` が実際のBGM配置・発音時刻です。`output/audio-preview.mp3` に3場面を各5秒抜き出した試聴用音声を保存しています。

## 素材

`assets/person.png`, `plant.png`, `beetle.png`, `worm.png`, `fly.png`: 描画プログラムで制作した透過スプライト。植物の絵は簡略化した共通表現です。`assets/key-art.png`: 生成したキービジュアル案（プレイヤーページに掲載、動画本体はスプライト演出）。

原台本指定の Plants Song は未収録です。4分30秒の歌唱部を30秒のオリジナル仮インストに短縮しています。実曲を入れる場合は音源と使用条件を確認したうえで、曲中の成長・受粉・枯死・種の各場面を同期して拡張してください。
